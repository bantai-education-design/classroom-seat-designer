# 学級座席デザイナー v1.0.0

> 🆓 **無料公開版**：小学校担任の先生向けに**無料**で公開しているアプリです。ライセンス認証やアカウント登録は不要です。

「学級座席デザイナー」は、小学校担任が児童名簿から座席表を作成し、教師用・掲示用に印刷できるアプリケーションです。座席を全自動で決めるのではなく、自動配置や配慮条件チェックによって**担任の判断を助ける道具**として設計しています。**Web版**と、インストール不要の**Windowsポータブル版（exe）**の2形態を無料で提供しています。

### 🚀 Web版 公開URL
**[https://bantai-education-design.github.io/classroom-seat-designer/](https://bantai-education-design.github.io/classroom-seat-designer/)**

### 💻 Windowsポータブル版
インストール不要のexeファイル（ZIP形式）です。GitHub Releases から最新版をダウンロードできます。オフライン環境（学校の校内ネットワークなど）でもそのまま利用できます。

## 💡 特徴・主な機能

### 1. 多彩な座席形態に対応
* **1人席**（通常の並び）
* **2人組席**（ペア学習や隣同士の活動用。ペアごとに結合された枠線やペア番号のラベルを表示）
* **班席**（2×2の4人グループ用。班ごとの外枠、境界線の点線化、班番号のラベルを表示）

### 2. 印刷形式の切り替えとA4最適化
* **教師用チェック記入型**: 各児童セルに出席番号、チェック欄、性別、身長などを表示し、配慮確認セクションも出力可能。
* **掲示用きれい版**: 教室掲示用に児童名のみを大きく表示する、シンプルで美しいレイアウト。
* **A4縦1ページ印刷**: A4用紙の縦横の印刷領域を極限まで広く使い、文字やグリッドが大きく鮮明に収まるよう最適化しています。

### 3. スマートな自動配置と配慮条件の反映
* **自動配置アルゴリズム**: ランダム配置、身長順（低い子を前方・中央へ）配置、男女交互配置に対応。また、ペア配置時には「近づけたい児童を同じペアに」「離したい児童を別ペアに」「男女ペア」などの細かい自動編成条件を追加できます。
* **固定席指定**: 指定した座席位置に児童を固定でき、自動配置時も最優先されて動きません。
* **配慮条件の設定とリアルタイムチェック**:
  * **前方希望**: 設定された児童を自動配置時に極力前方に配置。
  * **近づけたい子・離したい子**: 児童間の近接条件をチェックし、問題がある場合は教師用画面に注意・確認メッセージを表示（2人組席や班席の同一グループ内近接も考慮）。

### 4. 便利な表示カスタマイズと学級情報設定
* **漢字／ひらがな表示切り替え**: 低学年用に、名簿に登録された「ふりがな（ひらがな）」で座席を表示可能。姓と名の2行表示も維持されます。
* **名前サイズ調整**: 印刷・表示される名前のフォントサイズを「標準」「大きめ」「低学年向け」から選べます。
* **学年・学級名の入力とタイトル表示**: 「1年」「1組」のように学年と学級名を入力でき、タイトル部分に「1年1組 座席表」のように自然に整形して表示・印刷されます。

### 5. 便利なデータ管理
* **CSVデータ連携**: 出席番号、氏名、ふりがな、性別、身長のCSVインポート・エクスポートに対応。
* **JSON保存・読込**: 配座データ、配慮条件、名前の表示設定や学級情報を含めた全設定をJSONファイルでローカルに保存・読み込み可能。

## 🔒 児童情報の取り扱いについて

児童名簿・座席配置データ（CSV / JSONファイル）は外部サーバーへ送信せず、お使いの端末内にのみ保存されます。ただし、これらのファイルには児童の氏名等の**個人情報が含まれる場合があります**。ファイルの保存場所・共有方法・不要になったファイルの削除については、学校の情報管理ルールに従って十分ご注意のうえ管理してください。

## 📖 簡単な使い方の流れ

1. **名簿を入力または読み込む**:
   「名簿編集」モーダルから児童名簿を入力、またはCSVファイルから一括で読み込みます。
2. **学級名を入力する**:
   右側の設定パネルで「学年」と「学級名」を入力すると、タイトルに自動反映されます。
3. **座席形態と表示を設定する**:
   1人席・2人組席・班席などの「座席形態」や、名前の「漢字/ひらがな」「名前サイズ」を設定します。
4. **座席を決める**:
   「自動で配置する」ボタンを押すか、左側の名簿リストから児童をドラッグ＆ドロップして個別に座席に配置します。
5. **印刷（PDF保存）する**:
   教師用チェック記入型、または掲示用きれい版を選んで「印刷する」ボタンから印刷・PDF保存します。

## 💻 Windows専用アプリ版（ポータブル .exe）
* 学校のオフライン環境下でも動作する **Windows専用デスクトップアプリ版（ポータブル版 .exe）** を無料公開しています。
* インストール不要で、ZIPを解凍してexeを起動するだけで利用できます。
* 未署名アプリのため、初回起動時にWindows Defender SmartScreenの警告が表示される場合があります（「詳細情報」→「実行」で起動できます）。
* 最新版は GitHub Releases から入手してください。開発環境があれば `npm run electron:pack` でローカルビルドすることも可能です。

## 📦 開発・起動手順

```bash
# 依存パッケージのインストール
npm install

# 開発用サーバーの起動 (Web版)
npm run dev

# プロダクションビルド (Web版)
npm run build

# デスクトップアプリのローカル起動 (Electron開発用)
npm run electron:dev

# Windows用ポータブルexeのパッケージ作成 (ビルド)
# (※実行後、release/ フォルダ以下に 学級座席デザイナー-v1.0.0-portable.exe が生成されます)
npm run electron:pack
```
