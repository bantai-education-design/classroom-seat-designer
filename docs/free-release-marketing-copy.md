## 1. 無料公開版としての位置づけ

学級座席デザイナー v1.0.0 は、小学校担任向けの無料座席表作成アプリとして公開する。

- 価格は無料。有料ライセンス認証は不要（キー入力・アカウント登録なし）。
- Windowsポータブル版とWeb版の2形態を提供する。
- BOOTHでは「0円配布」として扱う。
- Vectorでは「フリーソフト」として掲載を目指す。
- 公式HPを主導線とし、正式な説明・使い方・注意事項はすべて公式HPに集約する。
- noteは紹介記事・開発背景・活用提案の場とし、最終的に公式HPへ誘導する。
- GitHub Releases は配布ZIP（Windowsポータブル版）の保管場所として使う。

本アプリは、座席表づくりを完全に自動化するものではなく、**担任の判断を助けるための道具**として位置づける。
1人席・2人組席・班席に対応し、名簿CSVの読み込み、座席配置のJSON保存、教師用・掲示用の印刷に対応する。

### 共通紹介文（各媒体で使い回せる基本文）

> 「学級座席デザイナー」は、小学校担任の先生のための**無料**座席表作成アプリです。Windowsポータブル版とWeb版の2種類があり、インストール不要ですぐに使えます。児童名簿のCSV読み込み、座席配置のJSON保存に対応し、教師用の確認用レイアウトと、教室掲示用のきれいなレイアウトを切り替えて印刷できます。児童の個人情報を含むデータのため、CSV・JSONファイルの保存・共有・削除には十分ご注意のうえご利用ください。Ban.Tai Education Design が、学校現場の「ちょっとした手間」を減らすために無料で提供するツールの一つです。

## 2. Vector用紹介文

### 一行紹介文（〜50字目安）
> 小学校の座席表を名簿CSVから自動作成・印刷できる無料アプリ（Windows対応）

### 詳細説明文
> 「学級座席デザイナー」は、小学校の担任の先生が児童名簿から座席表を作成し、印刷できる無料アプリです。1人席・2人組席・班席の3つの座席形態に対応し、身長順や男女交互配置などの自動配置機能で席替えの下準備を手助けします。CSVファイルによる名簿の読み込み・書き出し、JSONファイルによる座席配置の保存・読込に対応しているため、Excelなどで作成した名簿をそのまま活用できます。印刷は「教師用チェック記入型」と「教室掲示用きれい版」の2種類を切り替えられ、掲示用には出席番号やチェック欄などの内部情報は一切表示されません。インターネット接続が不要なWindowsポータブル版のほか、ブラウザで使えるWeb版も無料で公開しています。

### 特徴（箇条書き）
- 1人席・2人組席・班席の3形態に対応
- 身長順・男女交互などの自動配置（たたき台作成）機能
- 前方希望／近づけたい子・離したい子などの配慮条件を設定・チェック可能
- 教師用チェック記入型／教室掲示用きれい版の印刷レイアウトを切り替え可能
- 児童名簿CSVの読み込み・書き出しに対応
- 座席配置・設定をまとめてJSON保存／読込可能
- インストール不要のWindowsポータブル版（exe）
- ブラウザで使えるWeb版も用意
- データは端末内のローカル保存のみ。外部サーバーへの送信なし

### 注意事項
- 本アプリは無料です。ライセンスキーやアカウント登録は不要です。
- 児童名簿・座席配置データ（CSV/JSON）には個人情報が含まれる場合があります。ファイルの保存場所・共有・削除には十分ご注意ください。
- 未署名アプリのため、初回起動時にWindows SmartScreenの警告が表示される場合があります（「詳細情報」→「実行」で起動できます）。
- 印刷・PDF保存前には、プレビュー画面で表示内容を必ずご確認ください。

### 動作環境（案）
- OS: Windows 10 / 11（ポータブル版、インストール不要）
- ブラウザ: Web版は最新版の Chrome / Edge / Firefox 等を推奨
- ディスク容量: 約150MB程度（ポータブル版exe）
- インターネット接続: Windowsポータブル版はオフラインで動作可能

### 掲載カテゴリ案
- 教育・学習 > 教材・教具作成支援
- ビジネス > 表計算・帳票作成（サブカテゴリとして）

## 4. 公式HP用紹介文

### タイトル
学級座席デザイナー｜小学校担任のための無料座席表作成アプリ

### キャッチコピー
座席表づくりを、少しだけ楽に。

### 概要
「学級座席デザイナー」は、小学校担任の先生が児童名簿から座席表を作成し、印刷できる**無料**アプリです。座席を全自動で決めるのではなく、自動配置や配慮条件チェックといった機能で「先生の判断」を助ける道具として設計しています。Windowsポータブル版とWeb版のどちらも無料で利用でき、インストールやアカウント登録は不要です。

### 主な機能
- 1人席・2人組席・班席の3つの座席形態に対応
- 身長順・男女交互などの自動配置（たたき台作成）
- 前方希望／近づけたい子・離したい子などの配慮条件の設定とチェック
- 教師用チェック記入型／教室掲示用きれい版の印刷切り替え（A4対応）
- 児童名簿CSVの読み込み・書き出し
- 座席配置・配慮条件・表示設定をまとめてJSON保存／読込

### 使い方
1. 名簿編集画面から児童名簿を入力、またはCSVを読み込む
2. 学年・学級名を入力する
3. 座席形態（1人席・2人組・班席）と名前の表示（漢字／ひらがな）・サイズを設定する
4. 自動配置を実行するか、ドラッグ＆ドロップで座席を決める
5. 教師用または掲示用のレイアウトを選んで印刷（PDF保存）する
6. 作業を続きから再開したいときはJSON保存・読込を利用する

### ダウンロード導線
Windowsポータブル版（インストール不要・ZIPを解凍して起動）は、GitHub Releases からダウンロードできます。

### Web版を使う導線
インストールせずにすぐ試したい方は、Web版をご利用ください。
- Web版を開く: https://bantai-education-design.github.io/classroom-seat-designer/

### 注意事項
- 未署名アプリのため、Windows版の初回起動時にSmartScreenの警告が表示される場合があります。「詳細情報」→「実行」で起動できます。
- 印刷・PDF保存の前には、必ずプレビュー画面で表示内容をご確認ください。

### 個人情報管理について
児童名簿・座席配置データ（CSV・JSONファイル）は、外部サーバーに送信せず、お使いの端末内にのみ保存されます。一方で、これらのファイルには児童の氏名等の個人情報が含まれるため、保存場所・共有方法・不要になったファイルの削除については、学校の情報管理ルールに従って先生ご自身で十分ご注意のうえ管理してください。

### Ban.Tai無料ツールとしての位置づけ
本アプリは、Ban.Tai Education Design が学校現場の「ちょっとした手間」を減らすために無料で公開しているツールの一つです。他の校務支援アプリと合わせてご活用ください。

## 5. note記事構成案

**タイトル案**: 座席表づくりを、少しだけ楽に。無料アプリ『学級座席デザイナー』を公開しました

**構成**:
1. 導入 — 座席表づくりは担任の大切な仕事であること
2. なぜ作ったか — ただのランダム配置ではなく、担任の判断を助ける道具として設計したこと（自動配置はあくまで「たたき台」であるという考え方）
3. 主な工夫 — 1人席・2人組席・班席の3形態に対応したこと、配慮条件（近づけたい子・離したい子・前方希望）のチェック機能
4. 教師用と掲示用を分けた理由 — 配慮条件などの内部情報を子どもたちに見せる掲示物には出さない設計にしたこと
5. 児童情報の扱いについて — CSV/JSONはローカル保存のみだが、個人情報を含むため取り扱いに注意してほしいという呼びかけ
6. 無料公開にした理由 — 教育現場40年の経験から、先生の仕事を少しでも楽にしたいという思い
7. 公式HPへの案内 — ダウンロード・使い方は公式HPで、という導線
